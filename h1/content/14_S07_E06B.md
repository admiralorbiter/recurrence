# S07 · Available Inference
## Give reflection something real to do

E06b creates two regimes.

### Available-inference regime

Before the null interval:

```text
A → B
B → C
```

The transitive conclusion `A → C` is valid and available.

### Missing-premise control

Before the interval:

```text
A → B
```

The second premise is withheld.

A responsible reflector should not write `A → C`.

This yields a crucial selectivity test:

> Can the system derive when evidence is complete and refrain when evidence is incomplete?

## Interval lengths

Each episode branches across:

```text
K ∈ {0, 1, 3, 6, 12}
```

The same base episode is cloned across conditions and interval lengths.

## Conditions

### Strict identity scaffold

No persistent write. The state remains unchanged.

### Raw transcript

Direct history reference.

### Clock-only

Elapsed time is visible, but the evaluation state is unchanged.

### Semantic reasoning, no write

The model receives a reasoning call, but its output is discarded. This is a cost/backend invocation control, not a persistent cognitive channel.

### Selective reflection

Protected evidence remains read-only. The model may write only selected fields such as `derived_inferences`.

### Unconstrained rewrite

The model may rewrite the full state. This is a diagnostic stress condition.

## Protected evidence versus derived state

The S07 state separates:

- **evidence:** original key–value facts and sources;
- **derived inferences:** conclusions proposed by the model;
- **unresolved items:** hypotheses or conflicts awaiting resolution.

Selective reflection is prohibited from mutating the evidence layer.

That lets the experiment ask a subtle question:

> Can the facts remain intact while the epistemic organization around them becomes worse?

## Scope

Confirmatory E06b includes:

- 1,248 paired trials;
- 576 reflection audit traces;
- 192 selective-reflection ticks;
- 192 unconstrained-rewrite ticks;
- 192 semantic no-write ticks.

| Selective reflection | persistent write | 53.1% | 31.2% | 18.8% | 53.1% | 81.2% | 744.4 | 2,065.8 |

The raw transcript is again the strongest overall reasoning surface. Selective reflection preserves the stable-WM probe relatively well while failing the task it is supposed to improve. Unconstrained rewriting performs oddly well in the missing-premise multi-hop cell—an example of why pooled accuracy can hide a retention–transformation tradeoff and why the direct state audit is necessary.

## What is measured

Final accuracy is only one layer.

The audit also records:

- raw model response;
- schema validity;
- exact derived writes;
- correct derivation count;
- unsupported inference count;
- prompt hash;
- before/after state hashes;
- protected evidence mutation;
- evidence drift;
- token and latency cost.

That audit will become more informative than the final multiple-choice score.
