# The Unfinished Half
## Why H1 is not over

H1 runs from S04 through S09.

S04–S06 established the explicit-memory substrate and tested the first temporal contrast.

Three questions remain before the Horizon-1 gate.

## S07 — Quiet Interval / Null-Tick Screen

### Question

Can meaningful state changes happen **between** informative events?

A null interval contains no new task-relevant external information.

A meaningful positive result would need to survive:

- no-tick control;
- filler control;
- clock-only control;
- goal-only control;
- replay control.

The key danger is confusing “more computation” or “more rewriting” with meaningful temporal processing.

## S08 — Reset, Clone, and Swap

### Question

Can visible memory and current input be held fixed while **state history** changes later behavior?

This begins to move closer to causal history dependence.

If all effects continue to follow explicit memory, Level 1 remains transcript-equivalent.

## S09 — Metacognition and Ownership

### Question

Does scaffolded persistence change:

- future-failure prediction;
- source ownership;
- causal self-attribution;
- metacognitive accuracy?

This is where H1 reconnects to H0's self-monitoring questions.

## The H1 gate

H1 ends after S09.

The project should move into major H2 investment if at least one of the following is true:

1. Level 1 reveals an effect native recurrence can test more cleanly.
2. Level 1 produces a strong transcript-equivalent null, making hidden recurrence the necessary next comparison.
3. The metacognition and ownership tasks are reliable enough for hidden-state intervention.

## The question to carry into S07

> **If no new evidence arrives, can state evolution itself do something selective and causally useful—or does it merely drift?**

That is the next test.
