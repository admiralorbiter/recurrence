Claims that require calibrated language

“State is useless”

Too strong.

State-only calibration works, and clone cross-swap reaches 75% when state contributes distinctive out-of-history information.

Use:

State is readable and can steer, but has little independent leverage under balanced conflict with rich history.

“Quiet reflection is useless”

Too broad.

Use:

The tested explicit iterative write mechanisms do not reliably consolidate the available opaque derivation and can self-pollute state.

“The model recognizes itself”

Canonical E08 cannot distinguish Self-role anchoring from Alpha-token preference. E08c is testing that ambiguity.

Use:

Canonical E08 shows a primary-agent response attractor; exploratory E08c suggests the attractor follows the designated Self role.

“Scaffolded state changes metacognition”

Canonical E09 shows a format-conditioned interaction, but the first-order choices differ across formats. E09c is the fixed-target test.

Use:

The canonical format interaction is real at the full-process level; whether assessment format alone changes about the same decision remains a live question.

Claims H1 does not support

Unsupported

The model is conscious.

H1 has no instrument for phenomenal experience.

Unsupported

The model is not conscious.

A null behavioral result under prompt-level state does not settle consciousness.

Unsupported

StructuredSelfState is the model's real inner self.

It is an external prompt representation and experimenter control surface.

Unsupported

All autoregressive transformers must show transcript dominance.

Primary confirmatory evidence is from Qwen2.5-3B under specific tasks and prompts.

Unsupported

The model cannot do transitive reasoning.

S07 isolates persistent derivation writing, not universal reasoning ability.

Unsupported

Latent recurrence will create a private self-representation.

That is an H2 hypothesis, not an H1 conclusion.
