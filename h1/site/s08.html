In plain English

Changing episodic history changes behavior dramatically; changing structured state while history is fixed usually does much less. State is readable, but history has more leverage under balanced conflict.

S08

Which representation actually controls behavior?

A state-only prompt can trivially show that a model reads state. S08 asks the harder causal question.

In balanced conflict trials, behavior follows episodic history 64.1% of the time and structured state 32.0%.

A surgical one-slot state edit is adopted only 12.5% of the time while the untouched control slot is preserved 93.8%.

The qualification that matters

When a clone cross-swap state introduces a distinctive value absent from the branch history, state allegiance reaches 75%.

Structured state is causally readable and can steer when it contributes distinctive information. Under balanced contradiction with a rich episodic record, history has far more behavioral leverage.

Do not overread the mechanism

S08 does not prove an attention-layer explanation. It measures behavioral leverage under a controlled prompt-level conflict.
