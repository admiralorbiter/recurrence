In plain English

If deterministic state can be rebuilt later from the same events, its continuity is not irreducibly temporal. The main gains are compactness and avoiding lossy model reconstruction.

S06

The replay test

This is where H1’s definition of continuity gets much stricter.

Suppose a state is generated by applying a deterministic update rule to an ordered event history. If we save the history, can we reproduce the final state later?

The crucial contrasts

  • Scheduling: incremental − deterministic replay = +1.0pp, primary permutation p=1.0. The terminal states and prompts are identical by construction.
  • Reconstruction: incremental − model reconstruction = +20.8pp, a resolved reconstruction bottleneck.
  • Raw history: transcript is descriptively higher overall; the pooled incremental-vs-transcript difference is not resolved by the primary episode-level test.

Explicit deterministic persistence is not intrinsically temporal when the event history and transition rule remain externally available.

What online maintenance actually buys

A compact continuously available representation and protection from lossy one-pass reconstruction. At T=50 the structured-state prompt used about 60% fewer query tokens than the raw transcript while both scored 59.4% in that horizon slice.
