In plain English

Giving the model explicit history helps a lot. The raw transcript actually beats structured state here; structured state is chosen because it is easier to inspect and manipulate.

Memory without continuity

The first Level-1 question was basic: if we simply give the model explicit history, how much of the apparent “continuity problem” disappears?

The raw won the static benchmark. Structured state was chosen anyway—not as an accuracy champion, but because it was bounded, typed, inspectable, clonable, and easy to intervene on later.

A useful dissociation

The model-written narrative retained only 2 of 18 target key–value associations exactly; 3 were mutated and 13 omitted. Yet forced-choice delayed retrieval was far better than 11%.

Exact reproduction and downstream recognition are not the same demand.

What S04 does not show

It does not show continuity. It shows that an external record can recover a large amount of behavior that might otherwise be described too quickly as “memory.”

Research bridge · context, not validation
Research bridgeCognitive offloadingRisko & Gilbert (2016)

External tools can change a task’s information-processing demands. H1 can be read as engineered offloading whose causal status is then tested.

Research bridgeLost in the MiddleLiu et al. (2024)

Long-context models do not use all positions equally well, motivating compact state as an access/cost tool even when raw history contains more information.
