# Recurrence H1 Narrative — Full Story Edition
## Mnemosyne and the River

This folder is a drop-in replacement for the earlier mid-H1 narrative site.

## Purpose

A curious reader with no prior machine-learning or statistics background should be able to:

- understand the full S04–S09 experimental journey;
- see the apparatus, raw result patterns, hardening steps, and causal logic;
- distinguish stable evidence from post-confirmatory repairs and live extensions;
- connect H1 to relevant research without confusing analogy with validation;
- understand exactly what H2 must test next.

## Scope

- **31 guided HTML chapters** across six acts.
- Full canonical data tables for S04–S09.
- Interactive evidence explorers for each major sprint.
- Measurement-archaeology timeline.
- Human-memory and AI-systems research bridge chapters.
- Data atlas, claim ledger, source trail, and H2 boundary.
- Matching Markdown source chapter for every site page.

## Evidence status

- **Frozen core:** S04/E03 through S09/E09 raw confirmatory evidence.
- **Repaired analysis:** S09 raw trials remain frozen; response-preserving source inference and the format-block metacognitive interaction were repaired transparently afterward.
- **Live extensions:** E08c and E09c exploratory values are shown only with visible provisional labels. Their N=16 confirmatory results should replace the exploratory blocks before the final public freeze.

## Open the site

Open `site/index.html`.

No framework or build system is required. If local JavaScript is restricted:

```bash
python -m http.server 8000 --directory site
```

## Design principles

1. Science first, mythology second.
2. Bring the reader along for the whole failed-and-repaired adventure.
3. Observation ≠ effect estimate ≠ inferential decision ≠ mechanism.
4. No resolved difference ≠ equivalence.
5. Frozen evidence is visually separated from live extensions.
6. External research is context, not validation.
7. Synthesis itself requires provenance and regression checks.
