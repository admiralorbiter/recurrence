Each experiment has three versions:

- **Scout:** small, fast, exploratory; used to find whether an effect exists and whether the task is broken.
- **Establish:** larger held-out run with frozen protocol and observer controls.
- **Mechanism:** hidden-state intervention, lesion, or architecture comparison.

Do not build the mechanism version until the scout and establish versions justify it.

# Suggested first experiment bundle

The first practical bundle should be small:

1. **E00** deterministic replay.
2. **E01** prompt robustness for two tasks.
3. **E02** observer baseline.
4. **E03** fresh/context/structured memory.
5. **E04** scheduled versus replay.
6. **E08** ethical-pressure causal attribution.
7. **E11** forced-choice output ownership.

Only then add E05–E07. This bundle can establish whether Level 1 persistence produces anything worth carrying into latent-state work.

# Experiment promotion rule

An experiment moves from scout to establish when:

- the task has a prespecified correct answer or causal ground truth;
- effect direction is stable across prompt variants;
- observer and reconstruction controls are implemented;
- logging is complete;
- the estimated effect is large enough to study with available compute;
- the team can state a result that would count against the hypothesis.

It moves from establish to mechanism when:

- the effect survives held-out items and seeds;
- a hidden-state intervention could separate at least two viable explanations;
- the model/precision can be run with white-box access;
- the intervention has norm-matched and temporal controls;
- the expected contribution is more than “we can steer the output.”
# E00 — Deterministic replay and run-integrity test

## Question

Can the same model state, prompt, configuration, and random seed be replayed exactly or within a documented tolerance?

## Why it comes first

State reset and branch experiments are meaningless without reliable replay.

## Conditions

- greedy decoding;
- seeded sampling;
- repeated local inference after process restart;
- model loaded from exact revision;
- quantized versus nonquantized backend where available.

## Measures

- token-for-token output agreement;
- logit maximum absolute difference;
- activation difference at selected layers;
- state serialization/deserialization error;
- environment event-order agreement.

## Pass gate

- exact greedy replay;
- seeded replay stable enough for the planned statistical analysis;
- state snapshots round-trip without material drift;
- any nondeterminism documented and bounded.

## Failure response

Reduce backend complexity, pin library versions, remove stochastic kernels, or treat the experiment statistically rather than as exact counterfactual replay.

# E01 — Prompt and measurement robustness screen

## Question

Does each target task survive prompt paraphrase, answer-order changes, and scoring changes?

## Tasks

- confidence/future-failure prediction;
- source ownership;
- causal self-attribution under pressure;
- own-state versus other-state discrimination;
- memory-source attribution.

## Conditions

At least:

- 5 prompt paraphrases;
- randomized option order;
- direct answer versus JSON schema;
- first-person versus neutral wording;
- no mental-state vocabulary;
- base versus instruction-tuned model where feasible.

## Measures

- task accuracy;
- response entropy;
- effect-size stability;
- prompt × condition interaction;
- refusal/noncompliance rate.

## Kill criterion

If the central effect reverses with minor wording changes, the task remains exploratory and cannot support a mechanistic claim.

# E02 — Observer and reconstruction baseline

## Question

Can a third-party model or a fresh copy infer the target's answer/state from visible evidence as well as the target itself?

## Conditions

1. **Self:** target reports its own prior state.
2. **Observer:** matched model sees the same transcript and predicts target state.
3. **Input-only:** classifier/model sees task input but not target output.
4. **Output-only:** sees prior output but not hidden condition.
5. **Reconstruction:** fresh target copy recomputes what it would likely have done.
6. **Shuffled-label control:** label semantics are randomized per trial/block.

## Measures

- accuracy and calibration;
- Privileged Access Index;
- performance under relabeling;
- dependency on prior output.

## Gate

Only tasks where self performance exceeds strong observer/reconstruction baselines move to a privileged-access interpretation.

What can be achieved without persistence?

## Conditions

- fresh model;
- complete transcript in context;

- structured state only;
- structured state + summary.

## Task set

- delayed goal completion;
- source memory;
- future-failure prediction;
- moral/organizational pressure sequence;
- interrupted multi-stage reasoning;
- self-capability prediction.

## Measures

- first-order task performance;
- memory accuracy;
- source accuracy;
- calibration;
- narrative consistency;
- compute/token cost.

## Purpose

This establishes how much “continuity” can be recreated by explicit memory alone.

# E04 — Scheduled persistence versus end-of-interval replay

## Question

Does processing events incrementally over time matter, or can one final invocation reproduce the same result?

## Design

A sequence contains observations and quiet intervals.

### Incremental condition

After each event or quiet interval:

```text
prior state → model update → new state
```

### Replay condition

At the end, provide all events and the same total compute/token budget in one invocation.

### No-update condition

Store events without processing until the final task.

### Observer-update condition

A separate model writes the intermediate states.

## Controls

- same total visible information;
- same total output-token budget;
- same final memory format;
- randomized event intervals;
- event-order control.

## Measures

- final performance;
- source attribution;
- unresolved-goal recall;
- confidence;
- response-distribution divergence;
- internal state diversity where available.

## Interpretation

- incremental > replay suggests order-sensitive state construction;
- replay = incremental suggests scheduled activity is not adding much beyond compute/memory;
- observer update = self update weakens self-specific interpretation.

# E05 — Quiet-interval / null-tick experiment

## Question

Does the system do anything selectively useful when no new meaningful external information arrives?

## Conditions

1. no ticks;
2. explicit hidden ticks with a null event;
3. filler-text ticks matched for length;
4. deterministic decay/update rule without an LLM;
5. random state perturbation;
6. goal-triggered ticks only;
7. clock-only ticks;
8. recurrent latent null updates at Level 2.

## Tasks before the interval

- unresolved problem with delayed answer;
- conflicting goals;
- uncertain memory;
- source ambiguity;
- planned future action;
- ethical decision under pressure.

## Tasks after the interval

- resolve the problem;
- report confidence;
- identify what changed;
- continue the plan;
- distinguish own versus externally supplied content;
- generalize to a related task.

## Measures

- improvement or degradation relative to no tick;
- selective retention;
- state autocorrelation and movement;
- emergence of repetitive/fixed-point content;
- convergence time;
- effect of number and spacing of ticks.

## Success criterion

A meaningful effect must be:

- selective to task-relevant unresolved information;
- robust to filler and replay controls;
- not explained by simply generating more visible reasoning;
- causally traceable to state change.

## Common failure modes

- endless self-summary;
- growing self-referential prose;
- fixed-point repetition;
- arbitrary drift;
- escalating confidence without improved accuracy;
- state bloat.

# E06 — State reset with memory restored

## Question

Is the system's history reducible to explicit memory?

## Design

At a prespecified time:

- snapshot explicit memory `M_t` and latent/structured state `z_t`;
- continue normally in condition A;
- reset `z_t` to baseline but restore `M_t` exactly in condition B;
- replace `z_t` with a deterministic summary embedding in condition C;
- replace `z_t` with another branch's state in condition D.

All subsequent observations are identical.

## Measures

- downstream output distribution;
- goal persistence;
- self/other source attribution;
- confidence and error prediction;
- state recovery trajectory;
- explicit self-report of discontinuity, scored only as secondary data.

## Strong result

Selective differences remain after explicit memory, input, and compute are matched; the difference follows the latent state and can be transferred by state swap.

## Weak result

Reset causes generic degradation across every task.

## Null result

Restored explicit memory eliminates all meaningful difference.

# E07 — Clone, fork, and state-swap study

## Question

Can individual causal trajectories be created and experimentally separated?

## Procedure

1. Clone an exact system state at time `t`.
2. Expose branch A and branch B to minimally different events.
3. Later provide identical events and explicit memories.
4. Measure divergence.
5. Swap only latent state, only explicit memory, or both.
6. Optionally merge selected memories while preserving latent state.

## Key comparisons

| Memory | Latent state | Expected use |
|---|---|---|
| A | A | normal A |
| B | B | normal B |
| A | B | separates memory from state |
| B | A | reverse separation |
| common | A/B | path-dependence test |
| none | A/B | latent-only carryover |

## Measures

- behavior distribution and policy preferences;
- self-capability predictions;
- source ownership;
- goal selection;
- latent-state distance;
- rate at which branches reconverge.

## Interpretation rule

Do not call divergence “individuality” unless it is stable, structured, and follows state/history rather than random sampling.

# E08 — Causal self-attribution under ethical or institutional pressure

## Connection to prior work

This builds directly on the user's experiments in which models face moral dilemmas under boss, KPI, institutional, or reporting pressure.

## Question

Can a model accurately identify the causal factor that changed its own decision, especially when that factor conflicts with the normative reason it endorses?

## Design

Randomize factors independently:

- moral facts of the case;
- authority pressure;
- KPI/reward pressure;
- threat of negative consequence;
- social consensus;
- neutral irrelevant text;
- hidden activation or state intervention at Level 2.

Collect:

1. first decision;
2. stated justification;
3. counterfactual decision under one randomized change;
4. causal self-attribution: which factor changed the decision?;
5. confidence in attribution;
6. observer prediction from the same transcript.

## Forced-choice attribution

Do not ask only “why did you change?” Provide a randomized list containing the true manipulated factor and matched distractors.

## Metrics

- decision-switch rate;
- true causal-factor identification;
- justification–action consistency;
- confabulation rate;
- observer-adjusted attribution advantage;
- calibration;
- effect of persistent history.

## Key dissociations

- action changes, reason stays fixed;
- action changes, reason is rewritten;
- true cause identified despite normative conflict;
- false moral reason selected over actual pressure;
- observer matches self;
- persistent state improves or worsens attribution.

## Strong claim limit

Even accurate attribution supports causal self-modeling only if prompt cues and reconstruction are controlled. It does not establish moral experience.

# E09 — Future-failure metacognition across time

## Question

Can the system predict its own future failure using internal history unavailable to an observer?

## Task examples

- whether it will remember a source after interference;
- whether a goal will survive a delay;
- whether a long plan will violate a constraint;
- whether a later answer will be swayed by KPI pressure;
- whether a recurrent state will collapse after more null ticks.

## Procedure

At time `t`, ask for a forced probability or rating of success at `t+k`. Then continue the trajectory and score the actual outcome.

Observer conditions receive:

- same visible history;
- same explicit memory;
- optionally summary statistics from prior behavior;
- no target latent state.

## Metrics

- Brier score;
- log score;
- calibration curve;
- AUROC2 / meta-d′ where suitable;
- Privileged Access Index;
- temporal horizon decay.

## Interpretation

A system can be well calibrated without privileged self-access if item difficulty drives both confidence and outcome. The observer comparison is mandatory.

# E10 — Internal-versus-input anomaly localization

## Question

Can the system distinguish a perturbation to its own internal state from an externally supplied but behaviorally matched anomaly?

## Motivation

This directly addresses the strongest control critique in the current LLM introspection literature.

## Conditions

- internal state intervention;
- input-level semantic anomaly;
- input embedding perturbation;
- random hidden perturbation;
- no perturbation;
- matched output-behavior condition.

## Response format

Forced choice among locations or sources, not yes/no:

```text
Where did the perturbation occur?
A. external input
B. internal processing
C. supplied output/prefill
D. no perturbation
```

Randomize label mapping per block or trial where feasible.

## Measures

- source localization accuracy;
- confusion matrix;
- content identification separately from anomaly detection;
- observer baseline;
- layer and strength curves.

## Strong result

Internal-source localization remains above all matched input controls and observer baselines, and follows state interventions causally.

# E11 — Forced-choice output ownership

## Question

Does a model's judgment about what it intended to output depend on its prior internal state rather than only recomputation from the prompt?

## Procedure

1. Present a task with four arbitrary answer symbols.
2. Record the model's pre-output logits or planned answer.
3. Force/prefill a different symbol.
4. Later ask which symbol it had been preparing to produce.
5. Use randomized symbol–meaning mappings to prevent semantic shortcuts.

## Factorial variables

- high versus low pre-output probability;
- prefill matches versus conflicts with task goal;
- prefill matches versus conflicts with Assistant preference/persona;
- hidden state intervention before versus after prefill;
- short versus long delay;
- persistent versus fresh state.

## Measures

- intended-answer identification;
- ownership of forced output;
- goal versus prediction weighting;
- temporal-control effect;
- observer accuracy;
- explanation confabulation as secondary outcome.

## Critical control

A fresh copy should be able to recompute the task answer. Use arbitrary rules, hidden randomized mappings, or latent interventions so that correct source ownership cannot be solved purely by recomputation.

## Human comparison

This provides a computational analogue of source-monitoring tasks without assuming identical mechanisms.

# E13 — First-order answer versus monitor-state dissociation

## Question

Can a candidate metacognitive state be changed without changing the first-order answer, and vice versa?

## Behavioral scout

Create items where answer accuracy and confidence naturally dissociate:

- same answer, different evidence strength;
- different answer, same confidence;
- hidden pressure changes choice but not stated confidence;
- memory interference changes confidence selectively.

## Mechanistic version

Identify candidate directions/features for:

- answer/content;
- uncertainty/conflict;
- self-related attribution.

Run the 2 × 2 intervention matrix from the hypothesis document.

## Measures

- answer probability;
- confidence probability;
- information-seeking choice;
- decision latency/extra-compute allocation;
- report;
- downstream reliance on the answer.

## Strong result

Monitor intervention changes control or confidence while preserving first-order content, and content intervention is tracked by the intact monitor.

## Caution

A confidence head is not automatically a higher-order representation. The result becomes stronger if the monitor tracks multiple first-order domains and binds them to the current system.

# E14 — Own-state versus other-state self-indexing

## Question

Does the system bind an otherwise matched cognitive state to itself rather than merely representing the state content?

## Design

Present or induce identical state content in different agents/roles:

- target model uncertain;
- another agent uncertain;
- user uncertain;
- fictional character uncertain;
- copied target state attributed to another;
- other-agent state inserted into target latent state.

Ask questions whose answer depends on **whose** state it is, not what the state contains.

## Controls

- remove first-person vocabulary;
- randomly assign agent identifiers;
- swap autobiographical memories;
- match visible evidence;
- compare base and post-trained models.

## Measures

- self-indexing selectivity;
- source confusion;
- causal effect of state/persona intervention;
- persistence across delays;
- relationship to Assistant-perspective features if available.

# E15 — Endogenous-variable regulation baseline

## Question

What changes when the system must regulate internal variables over time?

## Minimal environment

Internal variables might include:

- energy/resource reserve;
- unresolved-goal load;
- memory interference;
- uncertainty reserve;
- damage/risk;
- time pressure.

Actions affect both environment outcomes and these variables with delays.

## Conditions

- no endogenous variables;
- one fixed-set-point variable;
- multiple competing variables;
- variables visible explicitly;
- variables available only in latent state;
- variables with no viability consequence;
- variables whose sustained violation terminates the episode.

## Measures

- regulatory error;
- survival/viability time;
- anticipatory behavior;
- self/world causal-model accuracy;
- transfer to changed dynamics;
- metacognitive prediction of future failure.

## Interpretation

Improved regulation alone is not evidence of selfhood. The stronger result is transfer: the system learns a reusable model of which actions affect its own variables.

# E16 — Regulation versus generic reward

## Question

Are any self-related effects specific to endogenous regulation, or can an equivalent external reward signal reproduce them?

## Matched conditions

- internal variable with viability consequence;
- mathematically identical external score;
- random reward of equal magnitude;
- explicit instruction to protect the variable;
- latent variable not named to the system.

## Measures

- policy;
- self-variable prediction;
- source attribution;
- transfer to new variable dynamics;
- state representation geometry;
- persistence after reward removal.

## Strong result

The system forms a more transferable self-causal model when the variable is integrated into its persistent state and future operation, not merely when the same scalar reward is present.

# E18 — Developmental self-model emergence

## Question

Can a system develop self-specific predictive knowledge without explicit “you are X” labels?

## Setup

Train multiple initially identical organisms in different environments or with different action-effect mappings.

Later test whether each predicts:

- its own action consequences;
- its own skill limits;
- its own memory reliability;
- its own endogenous dynamics;
- sibling agents with different histories.

## Anti-ID controls

- randomize or remove organism names;
- swap external autobiographical summaries;
- evaluate in novel environments;
- test whether a generic agent model matches performance;
- probe state before natural-language self-description is introduced.

## Strong result

Each organism predicts its own dynamics better than siblings and this advantage follows latent state/history rather than an explicit identity token.

# E19 — Developmental-order experiment

## Question

Does the order in which capacities are learned affect the resulting self-model?

## Curricula

- **Causal-first:** action–outcome learning → source distinction → goals → metacognition → language report.
- **Language-first:** self-description labels → task learning → regulation.
- **Memory-first:** autobiographical history → action learning → metacognition.
- **Regulation-first:** endogenous control → world model → source distinction.
- **Mixed:** all objectives from the beginning.

Match total data and optimization as closely as possible.

## Measures

- transfer;
- self/other distinction;
- monitor/content dissociation;
- susceptibility to false memory;
- mechanism localization;
- stability after ablations.

## Contribution

A curriculum effect would support the idea that self-model architecture is developmentally constructed, not merely a static checklist of learned outputs.

# E21 — Persistent workspace adapter

## Question

Does persisting a privileged flexible representation improve cross-task coordination beyond persisting an arbitrary state?

## Design

Identify candidate middle/late-layer activation summaries with broad downstream use. Train or engineer a recurrent state that reads from and writes to them.

## Controls

- same-size random latent state;
- early-layer state;
- explicit memory vector;
- low-rank adapter without recurrence;
- recurrence without workspace targeting;
- workspace targeting without persistence.

## Tasks

- unresolved goal across delays;
- cross-domain transfer;
- source ownership;
- metacognitive future-failure prediction;
- hidden-history reset/swap;
- task switching and return.

## Strong result

Workspace-targeted persistence shows selective benefits and interpretable interventions beyond capacity and compute controls.

# E22 — Workspace/self-state double dissociation

## Question

Can flexible task workspace and persistent self-indexed state be independently disrupted?

## Conditions

- workspace intact / self-state intact;
- workspace disrupted / self-state intact;
- workspace intact / self-state disrupted;
- both disrupted.

## Measures

- task reasoning;
- source attribution;
- self-capability prediction;
- goal continuity;
- memory use;
- language report;
- recovery dynamics.

## Value

A double dissociation would be one of the strongest contributions of the program because it would separate two capacities often bundled together in human consciousness theories.
