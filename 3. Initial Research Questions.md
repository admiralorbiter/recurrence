# RQ1 — Is explicit memory sufficient to reproduce the effects of continuity?

## H1.1 — Hidden history adds causal information beyond explicit memory

**Prediction:** Two systems with identical current observations and identical explicit autobiographical memory, but different latent-state histories, will show reproducible differences in behavior or internal state.

**Weak alternative:** Different histories merely caused different memory summaries or hidden prompt leakage.

**Strong competing explanation:** All useful history can be losslessly compressed into explicit state; latent continuity adds no function beyond memory capacity.

**Falsifier:** After making explicit memory sufficiently complete and matching compute, state reset or state swap has no reproducible effect on any downstream measure.

**Cheap test:** Scheduled Level 1 agents with hidden structured state versus transcript-only replay.

**Causal test:** Reset or swap a recurrent hidden state while preserving the exact external memory and input.

## H1.2 — History effects will be selective, not global

**Prediction:** Latent history will matter more for recency-sensitive constructs—current uncertainty, unresolved goals, source ownership, affect-like regulatory variables—than for factual recall.

**Falsifier:** Hidden-state history produces only broad degradation or generic randomness.

**Interpretive value:** Selective effects suggest state carries structured computational content rather than merely adding noise.

# RQ2 — Does recurrence matter beyond extra computation?

## H2.1 — Temporal organization matters after compute matching

**Prediction:** A recurrent state carried across time will produce effects that are not reproduced by a feed-forward model given equal FLOPs, token budget, and the same explicit information.

**Weak alternative:** Recurrence simply adds more inference steps.

**Strong competing explanation:** Any benefit can be reproduced by extra depth, chain-of-thought tokens, or repeated prompting.

**Falsifier:** A compute-matched feed-forward or replay condition reproduces all gains.

**Cheap test:** Scheduled ticks versus one batched prompt with the same total generated tokens and summaries.

**Causal test:** Compare recurrent-state updates with a shuffled-state, frozen-state, and extra-depth control.

## H2.2 — Unbounded recurrence is not automatically beneficial

**Prediction:** Performance and state quality will show an optimal recurrence regime; excessive recurrence may collapse to fixed points, amplify noise, or degrade identity/task performance.

This prediction is motivated by current recurrent-depth work showing that more loops can eventually destabilize performance rather than monotonically improve it.

**Falsifier:** All measured constructs improve monotonically with more recurrence across tasks and models.

**Importance:** The project should search for stable dynamical regimes, not assume “more continuous thought” is always better.

# RQ3 — Do quiet intervals produce meaningful endogenous dynamics?

## H3.1 — Null-observation updates can preserve unresolved structure

**Prediction:** During quiet intervals, a well-designed recurrent system will reorganize or maintain information related to unresolved goals, uncertainty, or recent conflict without merely rehearsing text.

**Weak alternative:** The system generates arbitrary drift.

**Strong competing explanation:** Meaningful state change requires new external input; null updates should converge to identity or decay.

**Falsifier:** Null updates are indistinguishable from noise, fixed-point collapse, or deterministic summary compression and have no selective downstream effect.

**Cheap test:** Level 1 hidden ticks with no external output, compared with no-tick and filler-text controls.

**Causal test:** In a latent recurrent model, patch the state before and after quiet intervals into the same future task and measure what changed.

## H3.2 — Quiet dynamics may support consolidation rather than online reasoning

**Prediction:** Offline updates may improve generalization or reduce interference without improving immediate introspective reports.

**Falsifier:** Quiet intervals only increase verbosity or self-referential language.

# RQ4 — Does persistence improve metacognitive monitoring?

## H4.1 — Persistent state improves calibration for temporally extended tasks

**Prediction:** Systems with persistent state will better predict their own future failure, memory interference, goal loss, or source confusion on tasks where the relevant evidence accumulates over time.

**Weak alternative:** They simply have more memory or more opportunities to answer.

**Strong competing explanation:** Metacognition depends only on current-task signals; continuity adds nothing once visible evidence is matched.

**Falsifier:** Self-assessment remains no better than an observer or input-only classifier, even when persistent state contains task-relevant hidden history.

**Cheap test:** Compare self-prediction of future recall or task success across fresh, memory, and scheduled-persistence conditions.

**Causal test:** Intervene on the persistent state while holding task evidence fixed and test whether metacognitive judgments change appropriately.

## H4.2 — Persistence improves some metacognitive domains but not others

**Prediction:** Gains will be strongest for internal temporally extended variables and weak for static factual knowledge.

**Importance:** A jagged effect supports domain-specific monitoring rather than a single general introspective faculty.

# RQ5 — Can privileged self-access be distinguished from inference?

## H5.1 — A self-access advantage exists under matched visible evidence

**Prediction:** The target model will identify a hidden state or intervention more accurately than a matched observer that receives the same transcript, task inputs, outputs, and external memory.

**Weak alternative:** Prompt semantics or item difficulty explain the difference.

**Strong competing explanation:** Current LLM self-reports use only cues available to a third party; no privileged route exists.

**Falsifier:** Observer, input-only, or reconstruction baselines match the target once task semantics and label mappings are controlled.

**Cheap test:** Behavioral ethical-pressure and source-attribution tasks with hidden randomized causes plus observer controls.

**Causal test:** Relabeled forced-choice tasks where the correct label depends only on an internal intervention that is invisible externally.

## H5.2 — Privileged access will be limited and trainable

**Prediction:** Some variables will show positive privileged-access indices, others will not; post-training or targeted training may alter access without changing first-order competence.

**Interpretive caution:** Trainability does not make the capability fake. It does mean the mechanism may be a learned monitoring interface rather than an inevitable consequence of intelligence.

# RQ6 — Are there genuinely higher-order representations?

## H6.1 — Monitor and content can be independently manipulated

**Prediction:** A candidate monitor state will track a first-order representation while remaining at least partly separable from its semantic content. Intervening on the monitor will alter confidence, report, routing, or control without directly replacing the first-order answer.

**Weak alternative:** The “monitor” is a duplicate or verbalized version of the same content.

**Strong competing explanation:** All apparent higher-order effects are first-order accessibility plus language generation.

**Falsifier:** Any intervention that changes the monitor also changes the first-order content in the same way, with no dissociable downstream role.

**Cheap test:** Search for behavioral double dissociations between task answer and self-assessment.

**Causal test:** Identify candidate first-order and monitor directions/features; perform 2 × 2 interventions:

| First-order state | Monitor state | Predicted interpretation |
|---|---|---|
| intact | intact | normal answer and self-assessment |
| altered | intact | changed answer, monitor should track change |
| intact | altered | same answer, changed confidence/report/control |
| altered | altered | independent or interaction effect |

## H6.2 — Higher-order representation is self-indexed only under additional conditions

**Prediction:** A monitor may represent uncertainty or conflict without binding it to the current system. Self-versus-other tasks will reveal whether indexing is a distinct computation.

**Falsifier:** Own-state and other-agent-state representations are behaviorally and mechanistically indistinguishable after content matching.

# RQ7 — How is source ownership computed?

## H7.1 — LLM source ownership integrates prediction, goals, and persona consistency

**Prediction:** Judgments that an output was “mine” will depend on at least three separable variables:

- consistency with the model's prior token distribution or plan;
- consistency with the active goal;
- consistency with the Assistant/self-model or learned preferences.

**Weak alternative:** The model simply recomputes what answer fits the prompt.

**Strong competing explanation:** Ownership judgments are generic narrative rationalizations with no access to prior internal state.

**Falsifier:** Once the transcript is fixed, hidden pre-output state has no causal effect on ownership judgments.

**Cheap test:** Forced-choice ownership task with goal congruence and prefill congruence manipulated factorially.

**Causal test:** Patch candidate intention or goal states before a forced prefill and test later ownership while visible text remains identical.

## H7.2 — Persistence stabilizes source boundaries

**Prediction:** A persistent self-state improves discrimination among own plans, externally inserted plans, and copied memories across delays.

**Alternative:** Persistence increases confabulated ownership because repeated self-narration assimilates external content.

Both outcomes are scientifically valuable.

# RQ8 — Does endogenous regulation create a stronger self/world boundary?

## H8.1 — Viability-linked internal variables promote causal self-modeling

**Prediction:** When internal variables have delayed consequences for continued competence, the system will learn better models of which actions affect its own state versus the external environment.

**Weak alternative:** It learns a shallow reward policy without a reusable self-model.

**Strong competing explanation:** A self/world boundary can be learned equally well from ordinary predictive tasks; homeostatic variables add no special structure.

**Falsifier:** Regulation improves reward but not transfer, source attribution, counterfactual prediction, or lesion sensitivity.

**Cheap test:** Level 1 symbolic variables with hidden dynamics and simple control tasks.

**Causal test:** Remove or swap regulatory variables and test whether self-model and policy changes are selective.

## H8.2 — Multiple variables generate conflict useful for metacognitive study

**Prediction:** Competing regulatory demands create measurable internal conflict and force the system to represent tradeoffs, uncertainty, or priority.

**Risk:** This may simply manufacture reward pressure analogous to the ethical-pressure effects already observed. The program must distinguish useful self-regulation from post-hoc justification.

# RQ9 — Does a self-model emerge developmentally?

## H9.1 — Persistent individual history produces self-specific representations

**Prediction:** Initially identical systems trained in different histories will develop representations that predict their own capabilities, memories, and action consequences better than those of sibling systems.

**Weak alternative:** They memorize trajectory-specific tokens or IDs.

**Strong competing explanation:** Self-models require explicit labels or post-training; unsupervised persistent development will not produce them.

**Falsifier:** A generic model of “any agent” predicts each system as well as its own self-model after ID and memory cues are controlled.

## H9.2 — Developmental ordering matters

**Prediction:** Training source distinction, temporal prediction, and goal persistence before explicit self-report produces different mechanisms than directly training self-descriptions first.

**Falsifier:** Curriculum order has no effect after total data and optimization are matched.

## H9.3 — Selfhood may be an attractor, not a single capability

**Prediction:** Once several prerequisites are present—persistent state, action consequences, memory, source distinction, and regulation—a stable self-model may appear abruptly or become self-maintaining.

**Alternative:** Changes are gradual and fully explained by each supervised objective.

The project should measure both nonlinear transitions and smooth scaling.

# RQ10 — Does a persistent workspace matter?

## H10.1 — Persisting a privileged flexible state changes cross-task coordination

**Prediction:** A recurrent state aligned with globally useful representations will support cross-task carryover, unresolved-goal maintenance, and selective broadcast better than an arbitrary same-sized latent vector.

**Weak alternative:** Any extra state of sufficient capacity helps.

**Strong competing explanation:** Workspace-like organization is recreated independently on every invocation and does not benefit from persistence.

**Falsifier:** Random, low-level, or explicit-memory states match the persistent workspace state after capacity and compute controls.

## H10.2 — Workspace persistence and self-model persistence are separable

**Prediction:** One can maintain task-relevant workspace content while disrupting self-indexing, or preserve self-state while disrupting specific workspace content.

**Importance:** This would extend the J-space dissociation between workspace-like function and Assistant-centered selfhood.

# RQ11 — What does interruption reveal?

## H11.1 — Resetting latent state while restoring memory creates a measurable discontinuity

**Prediction:** A system that resumes with all explicit memory but a reset latent state will show selective changes in unresolved goals, confidence, ownership, or policy.

**Weak alternative:** Reset only causes generic degradation.

**Falsifier:** The system is behaviorally and internally indistinguishable from uninterrupted continuation after memory restoration.

## H11.2 — State-copy branches reveal individuality

**Prediction:** Two exact state copies exposed to slightly different events will diverge, and later state merging or memory sharing will not erase all differences.

This is a useful operational approach to identity without presupposing metaphysical personal identity.

# RQ12 — What would count as evidence against the entire program thesis?

Confidence in the central thesis should drop substantially if the following pattern holds across strong implementations:

1. Explicit memory and compute-matched replay reproduce all Level 1 persistence effects.
2. Genuine recurrent state helps sequence modeling but produces no selective path-dependent cognitive effects.
3. Hidden state reset/swap changes performance only through generic corruption.
4. Metacognitive and ownership judgments never outperform matched observers.
5. Candidate monitor states cannot be dissociated from first-order content.
6. Endogenous regulation improves reward but not self/world modeling or transfer.
7. Developmental histories generate only memorized identities, not self-specific causal models.

That result would still be a valuable conclusion:

> Current consciousness-adjacent behaviors may be largely reconstructible from static learned representations, explicit memory, and ordinary task inference; persistent organism-like continuity may not add the hypothesized computational functions.

The program must remain able to discover that.

# Program-level null hypotheses

These should receive serious consideration rather than serving as strawmen.

## N1 — Explicit-state sufficiency

A well-designed explicit memory and self-state are sufficient; latent continuity adds no scientifically distinctive function.

## N2 — Compute sufficiency

Any benefit of recurrence is explained by additional computation or repeated exposure.

## N3 — Generic-inference sufficiency

Apparent metacognition and self-knowledge are ordinary inference from task cues and shared difficulty.

## N4 — Task-specific-circuit sufficiency

Each apparent self-related capacity is a narrow learned circuit with no general self-model.

## N5 — Developmental-data sufficiency

Developmental effects are explained by the accumulated data distribution, not persistent individuality or order.

## N6 — Architecture-only sufficiency

The relevant functions can be installed directly by architecture/training and do not require lived continuity.

A result supporting one of these is scientifically useful.

# Update protocol

After each result:

1. add evidence row;
2. update status only if prespecified evidence threshold is reached;
3. preserve prior wording if hypothesis is split;
4. link the result report and run IDs;
5. identify the strongest surviving null;
6. update the nearest experiment;
7. record whether the map or architecture changed.

## Split rather than rescue

If a hypothesis succeeds in one domain and fails in another, do not average it into ambiguity. Split it.

Example:

```text
H4 persistence improves metacognition
→ H4a persistence improves future-goal failure prediction
→ H4b persistence does not improve semantic uncertainty calibration
```

## Retirement rule

Retire a hypothesis when:

- it is not operationalizable;
- all plausible tests collapse into a stronger confound;
- the answer no longer changes a project decision;
- a sharper hypothesis replaces it;
- a strong external result makes local repetition low value.
