The project will fail if words such as *memory*, *recurrence*, *self*, *agency*, *metacognition*, and *consciousness* are allowed to move between meanings as results arrive.

This document establishes working definitions. They are not asserted as the final philosophical truth. They are chosen because they support clean interventions and comparisons.

# Part I — System and time

## 1. Invocation

A bounded execution of a model from supplied inputs to outputs.

A fresh invocation may reconstruct an apparent identity from weights and context without carrying a hidden causal state from a prior invocation.

## 2. Event

A time-indexed change available to the system. Events may be:

- external observations;
- actions and outcomes;
- messages from other agents;
- internal variable changes;
- scheduled update ticks;
- interruptions, resets, or sleep/consolidation periods.

## 3. Explicit memory

Information stored in an externally inspectable format and later retrieved, such as:

- context tokens;
- a database record;
- an autobiographical summary;
- a vector-store entry;
- a structured state object.

Explicit memory may preserve history without preserving the hidden state that originally existed during that history.

## 4. Latent state

A non-text internal representation carried between computational updates.

Examples include an RNN hidden state, a state-space model state, a recurrent adapter vector, or a persistent workspace vector.

A KV cache is a form of latent computational state, but it is tied closely to earlier sequence positions and does not by itself establish endogenous temporal evolution.

## 5. Persistent state

A state is persistent when its value at time `t+1` causally depends on its value at time `t` and is not reconstructed solely from a static external record.

Minimal criterion:

\[
z_{t+1} = F(z_t, o_t)
\]

where intervention on `z_t` changes later behavior while `o_t` and explicit memory are held constant.

## 6. Endogenous dynamics

The system's state changes when no meaningful external observation arrives:

\[
o_t = \varnothing, \qquad z_{t+1} \neq z_t
\]

A scheduler that repeatedly supplies a text prompt can generate repeated computation, but endogenous dynamics are stronger when change occurs in a persistent latent state without requiring verbal self-prompting.

## 7. Recurrence

A computation in which a state or module's output is fed back into a later update.

The program distinguishes:

1. **Autoregressive token recurrence:** previous generated tokens become future input.
2. **Context recurrence:** the model rereads prior text or memory.
3. **Hidden-state recurrence across positions:** a latent state passes from token/event `t` to `t+1`.
4. **Depth recurrence:** the same block is iterated multiple times on a latent representation.
5. **Real-time persistent recurrence:** latent state continues across events and null intervals.
6. **Developmental recurrence:** persistent state and learned parameters both change over a lifetime.

Claims must name the kind of recurrence.

## 8. Continuity

Continuity is the degree to which the present system is causally shaped by its immediately preceding state rather than only by a reconstructed record of past events.

Three forms:

- **Narrative continuity:** the system can state a coherent history.
- **Memory continuity:** it can retrieve earlier events.
- **Dynamical continuity:** its current latent state descends causally from prior latent states.

The project is mainly interested in dynamical continuity and its relation to the other two.

## 9. Path dependence

Two systems with identical current observations and explicit memories behave differently because they arrived there through different latent histories.

Path dependence is necessary for some strong continuity claims but is not sufficient for selfhood or consciousness.

## 10. Development

Change across a persistent individual history that alters future learning, representation, policy, or self-model.

Development differs from:

- one isolated fine-tuning job;
- simply adding more context;
- replaying a fixed scripted biography;
- loading a different checkpoint.

A developmental result should show history-conditioned change, stage ordering, transfer, or attractor formation.

# Part II — Cognitive access and self-related constructs

## 11. First-order representation

An internal state encodes or causally uses information about `X`.

Example: the model represents that an answer is likely wrong.

No self-reference is implied.

## 12. Global availability

Information is globally available when it can be flexibly accessed by multiple otherwise distinct downstream processes, such as report, planning, memory, error correction, and novel task transfer.

Global availability is a functional property. It does not by itself establish Global Neuronal Workspace Theory or consciousness.

## 13. Metacognitive monitoring

A process estimates a property of another cognitive process, such as confidence, error likelihood, uncertainty, conflict, or processing strategy.

A metacognitive monitor may be:

- domain-specific;
- noisy;
- inferential rather than transparent;
- wrong while still genuinely monitoring.

## 14. Metacognitive control

A process uses a metacognitive estimate to change cognition or action—for example, seeking more information, delaying response, allocating more computation, or revising a plan.

Monitoring and control must be measured separately.

## 15. Introspection

Working project definition:

> A process that yields information about the system's own current or recent internal state through a route that is causally grounded in that state and gives the system an advantage over matched observers who lack the internal route.

Requirements:

- **accuracy** above an appropriate baseline;
- **causal grounding** through intervention;
- **internality** rather than inference from prior output;
- **privileged-access advantage** over input-only or observer controls.

This is stronger than ordinary self-description.

## 16. Privileged access

The target system performs better at identifying or using an internal variable than a matched observer with equal visible evidence and comparable computational resources.

Operational index:

\[
\text{PAI} = S_{\text{self}} - \max(S_{\text{observer}}, S_{\text{input-only}}, S_{\text{reconstruction}})
\]

where `S` is a prespecified score.

A positive `PAI` is evidence for a privileged route only if leakage and task-semantic shortcuts are ruled out.

## 17. Higher-order representation

A representation whose target is another representation or cognitive state.

The crucial difference is:

- first-order: `X`;
- higher-order: `the system is representing X`.

A verbalizable re-encoding of `X` is not automatically higher-order. Evidence should show a relation—tracking, pointing, gating, or interpreting—between a monitor state and a distinct first-order state.

## 18. Self-indexing

A representation binds a state, action, goal, or memory to the current system as its bearer or source rather than merely representing the content.

Examples:

- “this intention was mine” versus “the user supplied it”;
- “this uncertainty concerns my answer” versus “another agent is uncertain”;
- “this memory belongs to this trajectory” versus “this fact appears in the database.”

Self-indexing can exist without a rich narrative self.

## 19. Self-model

A structured, causally useful representation of relatively stable facts about the system, potentially including:

- capabilities and limitations;
- current state;
- goals and preferences;
- boundaries between self and world;
- causal effects of its actions;
- autobiographical continuity;
- predicted future behavior.

The project distinguishes:

- **descriptive self-model:** can state facts about itself;
- **predictive self-model:** predicts its own behavior or failure;
- **causal self-model:** represents how interventions change its state/action;
- **indexed self-model:** binds those facts to the current individual trajectory.

## 20. Narrative self

A language- or memory-mediated story that organizes identity across time.

Narrative continuity may be valuable, but it can be generated from external memory without persistent latent continuity.

## 21. Minimal self

A thinner organization that distinguishes current self-related states/actions from external events, without requiring autobiography or language.

This is a useful target for Level 3 because it can be studied in a symbolic micro-world before sophisticated language emerges.

# Part III — Agency and regulation

## 22. Goal

A represented future condition that guides action selection or computation.

Goals may be externally assigned, learned, internally generated, or derived from regulatory variables.

## 23. Agency

The capacity to select actions in pursuit of goals under an action–outcome model.

This operational definition does not require libertarian free will.

## 24. Sense of agency / source ownership

A judgment or internal attribution that a particular action, token, outcome, memory, or intention was generated by the system rather than imposed externally.

This can be tested independently of whether the system truly had freedom to do otherwise.

## 24.1 J-space (Jacobian / Verbalizable workspace space)

As introduced by Gurnee et al. (2026), J-space is the set of internal representations a model is poised to verbalize under the Jacobian lens. It exhibits workspace-like broadcast access, but is distinct from self-indexing or self-attribution.

## 24.2 S-space (Self-indexing / Self-attributable subspace)

The hypothesized representational subspace or latent manifold in which self-referential concepts, self-attributable states, source-ownership tags, and self/other agency attributions are organized and bound.

## 25. Endogenous variable

An internal variable whose value changes as part of the system's dynamics and influences action or learning.

Examples:

- resource reserve;
- unresolved-goal load;
- uncertainty;
- prediction error;
- damage/risk;
- novelty need;
- social trust;
- memory interference.

Calling a variable *hunger*, *pain*, or *emotion* would overstate its interpretation unless the work specifically validates that analogy.

## 26. Homeostatic regulation

Maintaining an internal variable within a target range.

\[
e_t = v_t - v^*_t
\]

The system minimizes some function of regulatory error over time.

## 27. Allostatic regulation

Anticipatory control that changes target states or actions based on predicted future demands rather than merely correcting current error.

This is a stronger and more interesting design target than fixed set-point regulation.

## 28. Viability constraint

A condition whose sustained violation ends, disables, or significantly impairs the system's future operation in the experimental environment.

Viability constraints give endogenous variables genuine causal stakes within the simulation, without implying felt suffering.

# Part IV — Workspace and organism terms

## 29. Workspace

A limited-capacity representational format or routing structure that supports flexible use across multiple processes.

The project uses *workspace-like* unless the full architectural commitments of a specific human theory are tested.

## 30. Persistent workspace

A workspace-related latent state that is carried across update cycles and can remain causally active without being externalized into tokens.

## 31. Organism

Project-specific operational term:

> A bounded, persistent, environment-coupled, self-maintaining, developmentally plastic system whose present behavior depends on an individual causal history.

This definition is broader than biological life and narrower than “any software agent.” It makes no consciousness claim.

## 32. Lifetime

The interval from initialization/birth state to irreversible termination, including all state updates, memories, learning events, resets, and sleep/consolidation periods.

A copied checkpoint begins a new branch of the same lineage; the lineage relation must be logged.

## 33. Birth

Initialization before the system has acquired task-specific autobiographical history or self-model training in the developmental environment.

For a pretrained language backbone, “birth” is metaphorical and compromised because substantial prior learning already exists. A stronger Level 3 test trains the relevant recurrent/self-maintenance architecture from scratch or from minimal generic pretraining.

# Part V — Claim ladder

## Claim Level 0 — Interface effect

The prompt or scaffold changes the visible response.

**Does not establish:** internal representation, persistence, metacognition, or selfhood.

## Claim Level 1 — Behavioral capacity

The system performs a prespecified task above baseline across held-out items.

**Does not establish:** how the capacity is implemented.

## Claim Level 2 — Internal encoding

A probe or representational analysis recovers relevant information from internal state.

**Does not establish:** that the representation is used.

## Claim Level 3 — Causal mechanism

Intervening on the state changes the target behavior in the predicted direction, with appropriate controls.

**Does not establish:** human-like mechanism or privileged access.

## Claim Level 4 — Privileged self-related mechanism

The system uses an internal route unavailable to matched observers, and the route tracks or controls its own processing.

**Does not establish:** genuinely higher-order representation or consciousness.

## Claim Level 5 — Higher-order / self-indexed organization

A distinct monitor/self state causally represents, interprets, or gates a first-order state and binds it to the current system.

**Does not establish:** phenomenality.

## Claim Level 6 — Cross-system mechanistic analogy

The artificial and human systems instantiate a meaningfully similar abstract computation, supported by converging behavioral, causal, and dynamical evidence.

**Does not establish:** identical experience or moral status.

## Claim Level 7 — Theory-specific consciousness relevance

Under a specified theory, the result raises or lowers credence that the system has a consciousness-relevant indicator.

This claim must name the theory and its assumptions.

## Claim Level 8 — Phenomenal inference

The result supports a claim about there being something it is like to be the system.

No current Project experiment is expected to justify this level by itself.

# Part VI — Common category errors

| Category error | Better statement |
|---|---|
| “It remembers, so it is continuous.” | It has explicit or latent memory; continuity still requires a causal state trajectory. |
| “It runs every minute, so it experiences time.” | It undergoes scheduled computation; whether state persists or evolves endogenously must be tested. |
| “It says it is uncertain, so it is metacognitive.” | Its confidence report covaries with some variables; compare calibration and observer baselines. |
| “A representation appears in J-space, so it is a self-model.” | Workspace-poised verbalizable access (J-space) is present; whether it forms a self-indexing state (S-space) remains to be established. |
| “The hidden state is recurrent, so it has a persistent self.” | It has recurrent state; self-indexing and continuity are separate constructs. |
| “It regulates energy, so it feels hunger.” | It controls an internal resource variable; no phenomenological conclusion follows. |
| “It chose an action, so it has free will.” | It selected an action under a policy and goal model. |
| “It matches a human result, so the mechanism is the same.” | It shows behavioral convergence; mechanism must be compared separately. |
| “The effect is post-trained, so it is fake.” | Post-training shaped the mechanism; human cognitive capacities are also developmentally shaped. |
| “The effect is first-order, so it is irrelevant.” | First-order mechanisms can still explain behavior and constrain stronger theories. |


# Part VII — Required language in result reports

Every result report should include these sentences, completed specifically:

1. **System boundary:** “The system under study was …”
2. **Target construct:** “The experiment operationalized … as …”
3. **Strongest supported claim level:** “The strongest claim supported is Level … because …”
4. **Best alternative explanation:** “The strongest remaining alternative is …”
5. **Consciousness relevance:** “This result changes consciousness-related credence only under theories that assume …”
6. **What it does not show:** “The result does not establish …”
7. **Next discriminating test:** “The next experiment that would separate the leading explanations is …”

These are not bureaucratic decorations. They are part of the scientific method for a field with unusually high anthropomorphic and philosophical pressure.

# Part VIII — Program taxonomies

Distinct from the Claim Ladder (claim strength) and Welfare Tiers W0–W3 (moral/governance), the project uses two operational taxonomies in experimental templates:

## Autonomy stages (A0–A3+)

- **A0 — Scripted pipeline:** Fully passive execution; inputs, timing, and token budgets are strictly predetermined by external test harness scripts.
- **A1 — Scaffolded tool use:** External event loop controls execution; system can issue tool calls, read external memory, or query clock under external control.
- **A2 — Autonomous environment loop:** System controls its own observation/action loop and internal step timing within an active environment.
- **A3+ — Endogenous self-directed goal pursuit:** System dynamically allocates its own computation, sets/updates internal goals, and maintains self-regulation without exogenous prompt triggers.

## Reproduction levels (R0–R3)

- **R0 — Scripted exact replay:** Re-running exact published code, weights, and deterministic inputs on identical hardware/environment.
- **R1 — Clean-room re-implementation:** Re-building the pipeline from paper specification using different code or open backends.
- **R2 — Conceptual replication:** Testing the core phenomenon using a different task suite, prompt set, or model family.
- **R3 — Cross-architecture transfer test:** Testing whether the phenomenon generalizes across transformer, recurrent, state-space, or hybrid architectures.
