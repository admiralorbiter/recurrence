## 2. Reinterpret: What Recent Results Imply
A monolithic RNN forces one latent vector $z_t$ to simultaneously represent the current observation, previous history, sensor readout, and query projections through repeated squashing:
$$z_{t+1} = \tanh(W_z z_t + W_x x_t + b_z)$$
Every step compresses the entire prior state through the non-invertible $\tanh$ manifold. Under prefix supervision, the network discovers a "recency attractor" because the newest edge is the easiest signal to separate.

By introducing an **Additive Residual Accumulator**:
$$m_{t+1} = m_t + \Delta m_t, \quad \Delta m_t = \tanh(W_m m_t + W_c e_t + b_m)$$
the state $m_t$ acts as an additive linear communication bus. The network does not rewrite the accumulated relationship; it adds a context-conditioned relational increment $\Delta m_t$.

## 3. Reconnect: Cross-Discipline Connections
