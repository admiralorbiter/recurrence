# Research Promotion Audits Directory

This directory stores all formal promotion audits and human re-entry reports following experimental completion.

## Naming Convention
Promotion documents MUST follow the pattern:
```text
PROMOTION-<GATE>-<QUESTION_OR_TOPIC>.md
```
*Example:* `PROMOTION-E-Q17a_endogenous_transitivity.md`

## Purpose
Promotion audits document the quantitative outcome of the experiment relative to the frozen criteria, verify reproducibility and invariant checks, and provide the human decision point for advancing repository baselines.
