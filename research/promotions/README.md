# Research Promotion Audits Directory

This directory stores all formal promotion audits and human re-entry reports following experimental completion.

## Naming Convention
Promotion documents MUST follow the pattern:
```text
PROMOTION-<GATE>-<QUESTION_OR_TOPIC>.md
```
## Purpose & Status Vocabulary
Promotion audits document the quantitative outcome of the experiment relative to frozen criteria, verify reproducibility and invariant checks, and provide the human decision point for advancing repository baselines.

- `CANDIDATE`: Automated implementation and experimental verification complete; awaiting human epistemic review.
- `PROMOTED`: Formally accepted by human review; advances repository baseline.
- `REJECTED`: Falsified or failed acceptance criteria; baseline unchanged.
- `REVISED_CONTRACT_REQUIRED`: Findings warrant contract revision or new hypothesis before re-testing.
- `ESCALATED`: Epistemic boundary reached; requires human resolution.
