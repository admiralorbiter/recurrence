# H0 Guided Site v2

This is a multi-page static site generated from the Markdown chapters in `../content/`.

## Reader model

The target reader is a curious non-specialist. No prior machine-learning or statistics background is assumed.

## Progressive-disclosure features

- Dotted-underlined terms reveal short explanations on hover/focus.
- Clicking a term opens the full glossary.
- A persistent glossary drawer is available from every page.
- Every page has an optional plain-English recap.
- `toolkit.html` contains interactive explainers for Brier score, AUROC2 intuition, and confidence intervals.
- `observers.html`, `archaeology.html`, `result.html`, and `stress-test.html` contain page-specific teaching interactions.

No framework, no backend, and no external assets are required.
